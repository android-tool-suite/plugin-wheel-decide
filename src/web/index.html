        转盘预设

          保存为预设

          保存后可以随时切回这个转盘，临时转盘本身不会被保留。

          批量粘贴选项

          每行一个选项。行尾可以写数值，例如「吃火锅 3」「看电影,0.5」；以 # 开头的行会被忽略。

          随机是怎么算的

          每次抽取都会先按当前方案把每个选项换算成一份概率，再用系统的密码学随机源产生一个无偏的随机整数，落在哪一份就抽中哪个选项。整数运算不会累积浮点误差，取模偏差也用拒绝采样排除了。

          按权重

          每项概率按权重占比分配，例如权重 3 和 2 对应 60% 和 40%。评分、百分比和倍数原本使用相同的比例计算，现合并为一种方案；权重不要求合计为 100，同时等比例放大全部权重不会改变结果。

          softmax 温度

          温度越低越集中在高分的少数选项，温度越高越接近等概率。评分差距很大但又不想让低分项彻底出局时，调高温度或加一点概率下限。

          排名幂律

          忽略数值，只用列表顺序：第 k 项的权重是 1/k 的幂次。适合「心里已经排好优先级」的场景。

          概率下限

          给每个参与选项保底一份概率，避免某个选项永远抽不到。下限不会超过平均概率。
